
# Diretrizes de desenvolvimento e versionamento:

- Conexão SSh com o github - git@github.com:LVSA2004/coutinho-ink.git
- Conexão Web caso o SSH falhe - https://github.com/LVSA2004/coutinho-ink.git
- Este projeto usa github como remoto `origin`.
- Faça commits pequenos e frequentes, um por subtarefa concluída, com mensagens no padrão `tipo: descrição curta` (ex: `fix: corrige permissão de escrita no dataset`).
- Rode `git push` ao final de cada task completa, exceto se eu pedir explicitamente pra segurar.
- Nunca faça `git push --force` sem confirmar comigo antes.
- Toda alteração deverá ser salva em um novo branch, nada deve ser feito com o branch original do projeto, a não ser que eu mande você fazer isso explicitamente.
